# 배달머니 (Delivery Money)

배달의민족 커넥트와 쿠팡이츠를 함께 이용하는 배달 라이더를 위한 개인 수입·지출 관리 웹앱입니다.

## 서비스 주소
- 웹앱: https://delivery-money-phi.vercel.app/view-v2.html

## 문제 정의
배달 플랫폼별 정산 내역과 운행 시간, 유류비·식비·정비비 등의 지출이 분산되어 있으면 실제 순수익과 시간당 수익을 파악하기 어렵습니다. 배달머니는 기록을 한곳에 모아 하루 및 기간별 수익성을 확인하도록 돕습니다.

## 주요 기능
- 이메일 회원가입 및 로그인
- 배민커넥트·쿠팡이츠 수입과 배달 건수 기록
- 날짜별 운행 시간과 지출 입력
- 지출 항목별 상세 내역 관리
- 총수입, 총지출, 순수익 및 시간당 순수익 계산
- 최근 7일 수입 추이 및 플랫폼별 비교
- 요일별 순수익·배달 건수·시간당 수익 분석
- 최근 6개월 순수익 추이와 전월 대비 증감률
- 월말 예상 순수익, 목표 달성률 및 하루 필요 수익 계산
- CSV 내보내기 및 JSON 전체 백업·복구
- Supabase 데이터 저장과 계정별 클라우드 동기화
- 모바일·PC 반응형 화면

## 기술 스택
- HTML / CSS / JavaScript
- Supabase Authentication
- Supabase Database 및 Row Level Security(RLS)
- GitHub
- Vercel

## 데이터 구조
- `delivery_records`: 날짜별 플랫폼 수입, 배달 건수, 운행 시간, 지출 및 순수익
- `expense_items`: 날짜별 상세 지출 항목, 금액, 메모
- 사용자별 데이터 접근은 Supabase RLS 정책으로 본인 데이터에 한정합니다.

## 실행 및 배포
1. 저장소의 `view-v2.html`을 브라우저에서 엽니다.
2. Supabase 프로젝트 URL과 공개용 publishable key가 설정되어 있어야 합니다.
3. GitHub `main` 브랜치에 변경 사항을 반영하면 연결된 Vercel 프로젝트가 배포합니다.

## 포트폴리오 설명
이 프로젝트는 실제 배달 업무에서 발생하는 수입과 지출을 효율적으로 관리하고 싶다는 문제의식에서 출발했습니다. 초기에 단일 HTML 화면으로 시작해 기록 입력과 합계 계산을 구현하고, 이후 Supabase 인증·데이터베이스를 연결해 계정별 클라우드 저장 및 기기 간 동기화를 확장했습니다. 사용자가 실제로 확인하고 싶은 지표를 기준으로 요일별 효율, 월별 추이, 목표 달성 예상 기능을 추가했습니다.

개발 과정에서는 기능을 작은 단위로 나누어 구현하고, 브라우저에서 직접 입력·수정·삭제·백업 흐름을 확인하는 방식으로 개선했습니다. 아직 실제 사용자 규모의 부하 테스트와 다양한 기기·브라우저 호환성 검증은 진행하지 않았으며, 제출 전 체크리스트에 따라 추가 검증할 예정입니다.
